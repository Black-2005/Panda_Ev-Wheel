# 🎡 Panda EV Wheel — วงล้อสุ่ม

วงล้อสุ่มรายชื่อ/รางวัล ไฟล์เดียว (`index.html`) เปิดในเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งอะไร

## ฟีเจอร์
- ✍️ พิมพ์รายการได้เลย หนึ่งบรรทัด = หนึ่งช่อง, ใส่ `*น้ำหนัก` เพื่อเพิ่ม/ลดโอกาส (ช่องกว้างตามโอกาสจริง), ขึ้นต้น `#` เพื่อซ่อนชั่วคราว
- 🎯 สุ่มอย่างยุติธรรมด้วย `crypto.getRandomValues` และแสดง % โอกาสของแต่ละช่อง
- 🖱️ หมุนได้หลายแบบ: ปุ่มกลาง, คลิกวงล้อ, ปัด (flick) หรือกด `Space`
- 🔊 เสียงติ๊กตามช่อง + เข็มเด้ง, เสียงฉลอง, พลุกระดาษ, ไฟกะพริบรอบวง
- 🏆 หน้าต่างประกาศผล พร้อมปุ่มลบผู้ชนะ / หมุนอีกครั้ง หรือเปิด "ลบผู้ชนะอัตโนมัติ"
- 📊 ประวัติ + สถิติ คัดลอกผล หรือดาวน์โหลด CSV (รองรับภาษาไทยใน Excel)
- 🔀 เครื่องมือ: สลับ, เรียง, ลบซ้ำ, นำเข้าไฟล์ .txt/.csv
- 🎨 ชุดสี 8 แบบ, โลโก้ตรงกลาง, ธีมสว่าง/มืด, โหมดเต็มจอ (`F`)
- 🔗 แชร์วงล้อผ่านลิงก์ และบันทึกอัตโนมัติในเบราว์เซอร์
- 📱 ใช้งานได้ทั้งมือถือและคอมพิวเตอร์

## แชร์
- ลิงก์หลัก https://black-2005.github.io/Panda_Ev-Wheel/ เปิดวงล้อเปล่าให้ใส่รายการเอง (บันทึกในเครื่องของแต่ละคน)
- กด 🔗 แชร์วงล้อนี้ → ได้ลิงก์ที่มีรายการในตัว (คัดลอกให้อัตโนมัติ) คนที่เปิดจะเห็นวงล้อชุดนั้นแบบชั่วคราว ไม่ทับวงล้อของเขาเอง
  และกด "เก็บเป็นของฉัน" ได้ถ้าต้องการ
